Ipomoea_hederacea_BSA_2026

This is a script for a Bulked Segregant Analysis (BSA) of ivyleaf morning glory (Ipomoea hederacea) using a script from Mansfeld and Grumet, 2018, who developed the package QTLseqr. This package uses methods from Magwene et al. 2011 and Takagi et al., 2013 to conduct the BSA.

This script also maps significant SNPs to gene IDs from a genome annotation developed by Amanda Peake.

The two bulks are 4/5 lobed leaves (the “high” bulk) and 3 lobed leaves (“low” bulk).
